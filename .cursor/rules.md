# Code Generation Rules — RackTrack

You are working on RackTrack, a native Android app (Kotlin + Jetpack Compose) for scoring American pool **8/9/10 races and 14/1 continuous** (including **14/1 solo training**).

## Product shape (current)

- Landscape + portrait split-screen board on billiard cloth (`fullSensor`)
- Setup: game mode (8 / 9 / 10 / 14/1); race length or 14/1 distance + innings; who starts;
  **Solo** toggle on 14/1
- Race modes: **+1**, **Run out**, **Foul**; 9-ball Golden/Dry; 8-ball Early 8/Dry
- 14/1: clear-rack **+(On Table − 1)**, **PASS** / **FOUL** (balls-left modal), **BREAK −2** on opening
- Break/hand indicator; undo; club pause (duration only); end-of-match summary
  (**SHARE** + **SAVE** PDF + BACK)
- Local history: mode-scoped list, player filters, delete with confirm, reopen stats
- Styled PDF (header timing on right; footer `Generated by RackTrack` + version/build)
- Settings: cloth (incl. Golden), keep screen on, haptics, defaults, FFB rules link, About
- Semver in `gradle.properties` — trains in **`docs/00-release-trains.md`**
- No per-shot ball + pocket entry; never remote live scoring

## Before generating anything

1. **Trains / gates:** `docs/00-release-trains.md` (then `docs/06-roadmap-todo.md`).
2. Scope: `docs/01-product-specification.md`.
3. Monetization (1.2.0): `docs/09-monetization.md` — do not invent banners / mid-board ads /
   subscriptions / blocking ad waits.
4. Play store ops: `docs/08-play-store.md`.
5. Domain: keep `domain/` pure Kotlin (no Android / AdMob / Billing imports).
6. Structure/deps: `docs/04-architecture.md` + `gradle/libs.versions.toml`.
7. Conventions: `docs/05-conventions.md`.
8. Ambiguous FFB encoding: ask; PDF under `resources/` is authority when present.

## Hard constraints

- No RackTrack backend / auth / general networking in **1.x** except **AdMob + Play Billing + UMP**
  when implementing **1.2.0** per `docs/09-monetization.md`.
- Never build remote live multiplayer scoring (one device scores the match).
- Compose only; activity uses `fullSensor`.
- `domain/` never imports `android.*` / `androidx.*` / Room / Compose / ad SDKs.
- Felt colors live in `appearance/` — do not put Compose UI types in `domain/`.
- No new external dependency without flagging it (monetization SDKs expected for 1.2.0).
- AGP 9 has built-in Kotlin — do not apply `org.jetbrains.kotlin.android`.
- Do **not** add Hilt unless the user explicitly asks.
- Do **not** silently drop backlog items from `docs/06-roadmap-todo.md`.
- Do **not** publish guidance that ships ad-free Play production then adds ads later.
- Never commit `keystore.properties`, `*.jks`, or Play service-account JSON.

## Enforced quality

- No `!!`, no mutable public state, Coroutines/Flow only, sealed results, immutable domain models.
- No business logic inside `@Composable`.
- ktlint + detekt must pass.
